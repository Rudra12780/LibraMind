================================================================================
           LIBRAMIND — AI-POWERED SMART LIBRARY MANAGEMENT SYSTEM
                          PROJECT OBJECTIVES
================================================================================

1. PROJECT VISION & HIGH-LEVEL AIM
--------------------------------------------------------------------------------
The primary objective of the LibraMind project is to design, develop, and deploy
an intelligent, full-stack, cloud-ready Smart Library Management System (LMS)
that seamlessly bridges the gap between digital discovery and the physical 
library experience. 

By eliminating physical retrieval friction, preventing study space booking 
conflicts, providing explainable AI semantic recommendations, and automating 
circulation workflows, LibraMind modernizes traditional library infrastructure 
into a biophilic, stress-free, and high-efficiency academic environment.


================================================================================
2. GENERAL OBJECTIVES
================================================================================
1. Modernize Library Operations: Replace outdated OPAC card/search systems with 
   a responsive, high-performance web architecture.
2. Optimize Physical Retrieval: Eliminate student wandering and lost study time 
   by providing precise spatial navigation to shelves and books.
3. Maximize Study Space Utilization: Provide fair, transparent, real-time desk 
   and study pod booking without double-booking or disputes.
4. Enhance Research Discovery: Implement natural language semantic matching to 
   connect students with relevant titles even when exact keywords are unknown.
5. Automate Circulation Lifecycle: Provide end-to-end management of checkouts,
   renewals, return hand-offs, waitlists, overdue fees, and inventory audits.
6. Support Administrative Decision-Making: Equip librarians and administrators 
   with predictive demand forecasting and usage analytics.


================================================================================
3. SPECIFIC & FUNCTIONAL OBJECTIVES
================================================================================

[A] AI DISCOVERY & SEMANTIC RECOMMENDATION OBJECTIVES
--------------------------------------------------------------------------------
- Objective A1: Natural Language Conceptual Search
  Implement an in-memory TF-IDF (Term Frequency - Inverse Document Frequency) 
  vector engine combined with Cosine Similarity algorithms to allow natural
  language queries (e.g., "scalable cloud backends" or "deep learning neural nets") 
  with sub-15ms response latency.
- Objective A2: Transparent & Explainable AI (XAI)
  Provide explicit match rationales and keyword highlight tokens for every 
  search recommendation to ensure explainability and search transparency.
- Objective A3: Personalized Interest-Based Suggestions
  Capture student academic research interests during registration and dynamically 
  deliver tailored "Recommended for You" reading lists based on profile topics.
- Objective A4: Conversational Chatbot Assistant
  Incorporate an in-app interactive AI library assistant to answer policy, 
  operating hours, and book discovery questions.


[B] PHYSICAL STACK NAVIGATION & SPATIAL COORDINATE OBJECTIVES
--------------------------------------------------------------------------------
- Objective B1: 4-Tier Granular Spatial Indexing
  Map every catalogued title down to an exact 4-tier spatial coordinate:
  Floor Level -> Subject Section -> Shelf Aisle Code -> Specific Rack Unit
  (e.g., Floor 2 -> Section CS -> Shelf SE-04 -> Rack 03).
- Objective B2: Physical Copy & Barcode-Level Tracking
  Track each individual physical copy with a distinct barcode identifier 
  (e.g., LM-SE-04-C1) indicating individual copy status (Available, Borrowed, 
  Reserved, or Under Maintenance) and physical condition.
- Objective B3: "My Library Visit Planner" & Routing
  Enable students to compile a physical visit itinerary that automatically 
  groups selected books by floor/section, checks destination floor seat 
  occupancy, and provides an interactive on-shelf checklist.


[C] STUDY PODS & CONCURRENCY-SAFE SEAT BOOKING OBJECTIVES
--------------------------------------------------------------------------------
- Objective C1: Interactive Floor-by-Floor Pod Matrix
  Provide a live visual map of 40 study pods divided into specialized zones:
  Silent Focus Carrels, Collaborative Lab Rooms, and Daylight Window Nooks.
- Objective C2: Zero Double-Booking Concurrency Guarantees
  Enforce strict atomic database-level constraints using SQLite Partial Unique
  Indexes (seat_id, date, time_slot WHERE status = 'active') to guarantee that 
  race conditions and simultaneous booking attempts are serialized safely.
- Objective C3: Flexible Slot Reservations
  Allow verified students to reserve scheduled time slots with instant live 
  status indicators (Available, Occupied, Reserved, Maintenance).


[D] CIRCULATION ENGINE, QUEUEING & AUTOMATION OBJECTIVES
--------------------------------------------------------------------------------
- Objective D1: Rule-Based Loan Lifecycle
  Automate 14-day loan intervals with real-time due date countdowns, dynamic 
  overdue fine calculations ($1.00 per overdue day), and self-service renewals.
- Objective D2: Ordered FIFO Reservation Waitlist
  When all copies of a title are checked out, place patrons in a transparent 
  First-In, First-Out (FIFO) queue (e.g., "Queue Position #1 of 3").
- Objective D3: Automated Return Hand-Off & Notification
  Automatically transition an available returned book to "Reserved" for Queue 
  patron #1 and send an automated in-app pickup notification with a 48-hour 
  reservation holding window.


[E] MULTI-ROLE GOVERNANCE & ACCESS CONTROL (RBAC) OBJECTIVES
--------------------------------------------------------------------------------
- Objective E1: Student Workspace
  Enable students to monitor active loans, review hold queues, manage saved 
  wishlists, book study spaces, and receive direct administrative messages.
- Objective E2: Librarian Operational Station
  Provide desk librarians with rapid barcode loan checkouts, return check-ins, 
  queue staging, copy condition maintenance, and campus-wide broadcasting.
- Objective E3: Administrator Command Console
  Equip administrators with user role management, system diagnostics, full CSV 
  catalog backup exports, and immutable audit logging for security compliance.


[F] ANALYTICS & PREDICTIVE DEMAND FORECASTING OBJECTIVES
--------------------------------------------------------------------------------
- Objective F1: Circulation & Velocity Analytics
  Generate real-time visual charts tracking monthly checkout volumes, category 
  density distributions, top-borrowed books, and peak seat utilization hours.
- Objective F2: 30-Day Predictive Stockout Forecasting
  Implement a predictive algorithm combining borrowing velocity, category hold 
  depth, and active waitlist queues to forecast demand spikes and proactively 
  flag titles at risk of stockouts.


[G] ERGONOMICS & BIOPHILIC DESIGN OBJECTIVES
--------------------------------------------------------------------------------
- Objective G1: Biophilic Visual Aesthetic
  Implement a nature-inspired aesthetic using soothing greens (Forest Green, 
  Sage, Botanical Green) and soft cream backgrounds (#FAF8F1) to reduce 
  screen fatigue during extended academic sessions.
- Objective G2: Responsive & Micro-Interactive Interface
  Deliver a clean, lightweight Vanilla CSS design system with custom typography 
  (Outfit and Newsreader) and subtle 200ms cubic-bezier micro-animations.

acceptance criteria:
  [✔] Scenario 1 : Semantic AI topic query returns relevant titles with rationale.
  [✔] Scenario 2 : 4-Tier shelf coordinates and copy status reflect accurately.
  [✔] Scenario 3 : Simultaneous borrowing requests prevent duplicate copy loans.
  [✔] Scenario 4 : Out-of-stock items enforce ordered FIFO queue positions.
  [✔] Scenario 5 : Book return triggers immediate hand-off and pickup alert.
  [✔] Scenario 6 : Concurrent seat booking attempts result in safe single winner.
  [✔] Scenario 7 : Side-by-side comparison matrix evaluates up to 3 titles.
  [✔] Scenario 8 : Visit Planner groups books by floor and verifies seat density.
  [✔] Scenario 9 : Role-Based Access Control blocks unauthorized endpoint calls.
  [✔] Scenario 10: Notification center reflects real-time unread state changes.
  [✔] Scenario 11: Analytics engine generates accurate 30-day demand forecasts.
  [✔] Scenario 12: Regression tests verify database WAL mode and ACID integrity.

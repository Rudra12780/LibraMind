1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
Project Name : LibraMind
Tagline      : AI-Powered Smart Library Management System (Biophilic Design)
Stack        : React 19 + Vite (Frontend) | Node.js + Express 5 (Backend) | 
               SQLite3 with WAL Mode (Database)
Design Theme : Biophilic Aesthetic (Forest Green #344E41, Botanical #52734D,
               Soft Cream #FAF8F1, Warm Beige #F3EBDD)

LibraMind is an intelligent full-stack library management system that bridges the
gap between online digital catalog discovery and the physical library experience.
It eliminates the three most frustrating bottlenecks students and librarians face:
  1. Finding where a book is physically located in a multi-floor building.
  2. Finding and reserving quiet study pods without crowding or double-bookings.
  3. Finding books by topic concept or research intent when exact titles are unknown.


================================================================================
2. CORE PROBLEMS SOLVED
================================================================================
* PROBLEM 1: PHYSICAL STACK CONFUSION
  Traditional OPAC library systems only provide a Dewey Decimal number. Students
  wander aimlessly across multiple floors, sections, and aisles trying to locate
  a book.
  -> LibraMind Solution: 4-Tier Spatial Coordinate Hierarchy giving exact Floor,
     Section, Shelf Code (e.g. Shelf SE-04), and Rack Number (e.g. Rack 03).

* PROBLEM 2: STUDY SEAT FRICTION & DOUBLE-BOOKING
  During exams, students walk across campus only to find all study pods occupied,
  or experience disputes when two people attempt to reserve the same seat.
  -> LibraMind Solution: Visual interactive floor-by-floor seat map with atomic
     database-level constraints preventing race conditions and double-bookings.

* PROBLEM 3: RIGID KEYWORD SEARCH
  Basic SQL search fails when students remember concepts rather than exact titles.
  -> LibraMind Solution: In-memory TF-IDF (Term Frequency - Inverse Document
     Frequency) vector engine with Cosine Similarity matching and explainable AI.

3. SYSTEM ARCHITECTURE & TECH STACK
================================================================================
The project strictly separates frontend and backend codebases:

[ FRONTEND CLIENT ] -> Port 5174
  - React 19: High-performance single page application.
  - Vite 8: Instant Hot Module Replacement and production bundling.
  - Lucide React: Cohesive icon design system.
  - Vanilla CSS Design System: Biophilic tokens, custom typography (Outfit and
    Newsreader), zero bulky CSS framework bloat.
  - Context API: AuthContext (JWT sessions) & NotificationContext (3s polling).

[ BACKEND API SERVER ] -> Port 5000
  - Node.js & Express 5: Modular RESTful routing across 9 route domains.
  - better-sqlite3: Ultra-fast synchronous SQLite driver with Write-Ahead Logging
    (WAL) for high-concurrency ACID transactions without deadlocks.
  - JWT Authentication & bcryptjs: Industry standard password hashing and RBAC.
  - Automated Scheduler: Cron engine managing $1/day overdue fines and hold queue
    pickup expirations.

[ DATA & STORAGE LAYER ]
  - Persistent SQLite database located at `backend/libramind.db`.
  - Partial Unique Indexes enforcing strict data integrity.

4. KEY FEATURES & MODULES
================================================================================

1. AI TOPIC FINDER & SEMANTIC SEARCH
   - Tokenizes and cleans natural language queries (e.g. "scalable cloud backend").
   - Computes TF-IDF vector embeddings against book titles, summaries, and topics.
   - Calculates Cosine Similarity rankings in under 15 milliseconds.
   - Displays transparent match explanations showing matched keywords.
   - Captures student academic interests during registration to deliver
     personalized "Recommended for You" carousels.

2. 4-TIER SHELF STACKS & COPY-LEVEL BARCODE TRACKING
   - Every book contains spatial coordinates: Floor -> Section -> Shelf -> Rack.
   - Individual physical copies are tracked with unique barcodes (e.g. LM-SE-04-C1).
   - Live availability counters: Shows available, borrowed, and maintenance copies.

3. INTERACTIVE STUDY PODS & CONFLICT-SAFE SEAT BOOKING
   - 40 dedicated study pods across Silent Focus, Collaborative Labs, and Window Nooks.
   - Concurrency Safety: SQLite Partial Unique Index enforces zero double-bookings:
       CREATE UNIQUE INDEX idx_seat_active_reservation 
       ON seat_reservations (seat_id, date, time_slot) 
       WHERE status = 'active';
   - Simultaneous reservation attempts are safely serialized: one succeeds and the
     second receives an instant friendly conflict notification.

4. CIRCULATION ENGINE & FIFO WAITLIST QUEUE
   - 14-day standard borrowing window with dynamic countdown days.
   - Automated overdue fine calculation: Levies $1.00/day fine on overdue books.
   - Self-service 1-click renewals (up to 2 times if no holds are pending).
   - Ordered FIFO waitlist queue: When all copies are borrowed, students join
     a waiting queue (e.g. "You are #1 of 3 in queue").
   - Automatic Hand-Off: When a book is returned, the system marks the copy reserved
     for Queue #1 and fires an instant pickup alert with a 48-hour pickup window.

5. BOOK COMPARISON MATRIX
   - Compare up to 3 books side-by-side.
   - Evaluates edition, publisher, shelf coordinates, total vs. available copies,
     and category metrics simultaneously.

6. MY LIBRARY VISIT PLANNER
   - Add books to a personalized visit itinerary.
   - Automatically groups reading lists by Floor and Section.
   - Shows live seat occupancy on destination floors before the student walks over.
   - Interactive checklist allowing students to check off books as found.

7. ROLE-BASED ACCESS CONTROL (RBAC)
   - Student Portal: Active loans, due date countdowns, hold queue tracking,
     wishlist, and administrative messages.
   - Librarian Station: Fast barcode checkout, return processing, hold queue
     staging, copy repairs, and institution-wide announcements.
   - Admin Console: User management, role elevation, direct patron messaging,
     system audit logs, database integrity diagnostics, and CSV catalog exports.

8. NOTIFICATION CENTER & ADMIN MESSAGES
   - Real-time notification drawer (Bell icon in Navbar) with 3-second polling.
   - When an Admin or Librarian sends a direct message to a student, it appears:
       a) In the Notification Bell dropdown with an [ADMIN] badge.
       b) Inside the Student Dashboard under "Direct Messages & Announcements".
   - One-click "Mark as Read" and "Mark All as Read" capabilities.

9. CIRCULATION ANALYTICS & DEMAND FORECASTING
   - Monthly loan volume trends and category distribution charts.
   - Seat occupancy density heatmaps.
   - 30-Day Predictive Demand Forecast model combining circulation velocity,
     hold depth, and active queue counts to flag inventory stockout risks.

5. DATABASE SCHEMA
================================================================================
The SQLite database (`backend/libramind.db`) consists of 9 core tables:
  1. `users`              : id, name, email, password_hash, role, membership_id, interests
  2. `books`              : id, title, author, isbn, category, floor, section, shelf, rack, total_copies, available_copies
  3. `book_copies`        : id, book_id, barcode, copy_number, status, condition
  4. `loans`              : id, user_id, book_id, copy_id, loan_date, due_date, return_date, status, fine_amount
  5. `reservations`       : id, user_id, book_id, queue_position, status, reserved_at, ready_until
  6. `seats`              : id, seat_number, floor, section, has_power, has_monitor, status
  7. `seat_reservations`  : id, seat_id, user_id, date, time_slot, status
  8. `notifications`      : id, user_id, title, message, type, link, is_read, created_at
  9. `audit_logs`         : id, user_id, action, details, ip_address, timestamp
